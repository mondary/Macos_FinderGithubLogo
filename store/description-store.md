## Description longue

### FR

**FinderGitBadge** affiche un badge Git/GitHub dans le Finder et applique une icône personnalisée aux dossiers de projets GitHub. Une app menubar regroupe les actions rapides.

#### ✨ Fonctionnalités clés
- **Badge Finder Sync** — pour les dossiers Git / GitHub
- **Script d'icônes** — remplace l'icône des dossiers GitHub
- **Menubar app** — actions rapides : refresh, logs, script
- **Dossiers observés par défaut** — `~/Documents` et `~/Documents/GitHub/PROJECTS`

### EN

**FinderGitBadge** shows a Git/GitHub badge in Finder and applies a custom icon to GitHub project folders. A menu bar app groups the quick actions.

#### ✨ Key features
- **Finder Sync badge** — for Git / GitHub folders
- **Icon script** — replaces folder icons for GitHub repos
- **Menu bar app** — quick actions: refresh, logs, script
- **Default watched folders** — `~/Documents` and `~/Documents/GitHub/PROJECTS`
